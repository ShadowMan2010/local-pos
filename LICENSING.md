# Licensing

Local POS uses a dual-licensing model:

## Open Source License (AGPL-3.0)
The core POS functionality is licensed under the [GNU Affero General Public License v3.0](LICENSE). This means if you modify and host this software as a service, you must share your source code.

## Commercial License
For businesses that want to use Local POS without AGPL-3.0 obligations (e.g., proprietary SaaS offerings), commercial licenses are available. See [COMMERCIAL-LICENSE.md](COMMERCIAL-LICENSE.md).

## Premium Features
Some advanced features require a valid license/subscription:
- AI-powered catalog scanning (Gemini/OpenAI)
- Voice ordering via WhatsApp
- Advanced WhatsApp automation (broadcast announcements, payment screenshot handling)
- Cloud sync and multi-store management (coming soon)

These features are gated by the license system. Core POS functionality (billing, products, inventory, receipts) remains fully open under AGPL-3.0.
